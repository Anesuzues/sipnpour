# Sip, Pour & Unwind

A luxury event landing page for Candid Candles & More — a private wellness and lifestyle experience for women.

## About

"Sip, Pour & Unwind" is a single-page luxury event landing page showcasing a premium wellness experience featuring:
- Yoga Session
- Candle Making Experience
- Wine Tasting
- Real Conversations & Story Sharing

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Radix UI Components

## Getting Started

### Prerequisites

- Node.js 18+ or Bun

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
